Encounter codes

Five codes that change the Pokémon you meet. Add each one as its own cheat so you can tick them on and off separately. Any combination works; all 32 were tested.

Codes 2–5 cover

Wild encounters are the random ones from an area's table: grass, caves, surfing, fishing, Rock Smash. Wild + static also covers the one-off Pokémon you walk up to and battle, like the legendaries, Kecleon and the red Gyarados (all 18 in the ROM start the same way). GG: 00 male, FE female. At 0x0823C052 the wild routine takes the gender Cute Charm picked, or "any" when Cute Charm doesn't apply. The code puts GG there instead, and at 0x08200858 in the static routine, and the personality roller keeps rolling until the gender matches. For a species with only one gender, or none, that loop would never end, so the patch at 0x081B3AF6 makes those species accept the first roll, which always has their only gender. Any other part of the game that asks for a gender the species can actually have gets the same result as before.

Setup. Type: Action Replay MAX or Autodetect for the encrypted codes; raw codes need Autodetect. Don't add a master code. All five patch the game in mGBA's memory only. Your .gba file is never changed.

Untick a code before you remove it. Unticking restores the original instructions right away. If you press Remove while a code is still ticked, mGBA drops the cheat from the list but leaves the patch in memory: nature and gender stay forced, even after a reset, until you restart mGBA or load the ROM again. This applies to all five codes.

Synchronize and Cute Charm. In this ROM, Synchronize doesn't pass its nature on to wild or static Pokémon: every entry of the lookup at 0x086FA67C points to a check that returns 0. So Code 4 is the only way to set a nature. Cute Charm still works two times in three without the codes. With Code 5 on, the gender you pick replaces it.

Found along the way. This ROM's normal shiny odds are 1 in 256 (the check at 0x081B6834 compares against 0xFF), not 1 in 4,096. The Shiny Charm adds 2 extra rolls.

Scope. With Wild encounters picked, codes 2–5 act only on random encounters from an area's encounter table. Wild + static adds every Pokémon an event script sends into a wild battle, through the setwildbattle script command that all 18 static encounters in the ROM use. Gifts, eggs, trainers' Pokémon and roaming Pokémon are made by other routines and aren't changed by either version. Code 1 also covers gifts and eggs.

Wild encounters by location

Search by place name or by Pokémon, or pick a marker. The map is the game's own Fly map, captured in the emulator. Chances are per encounter, from the game's slot tables.

One area. 6Several areas share that spot on the Fly map, and the number says how many. The 6 is both National Park areas plus all four Distortion World areas. Click a marker or a place name to open it, and click it again to close it. On a numbered marker, each click opens the next area, and the click after the last one closes it. Hover a marker to see its areas' names.

How the odds were read and checked

0x08E92194
Wild encounter table: 142 map entries × 84 bytes. Each has 4 time-of-day slots, but only the first is filled and the fishing code always reads that one, so encounters don't change with time.
0x0823BE90
Grass/cave slot pick: 20, 20, 10, 10, 10, 10, 5, 5, 4, 4, 1, 1 % (lookup table at 0x08E91A80).
0x0823BF14
Surfing and Rock Smash: 60, 30, 5, 4, 1 %.
0x0823C908
Fishing: Old Rod 70, 30 %; Good Rod 60, 20, 20 %; Super Rod 40, 40, 15, 4, 1 %.
0x0823BB04
Step check: an encounter happens when a random number under 2880 is below the area's rate × 16, before bike, repel and ability modifiers.
0x0823BC3C
Level: picked evenly between the slot's minimum and maximum.
